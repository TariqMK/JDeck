      How to let JDeck connect to JDownloader
      1. On the JDownloader computer, open Settings > Advanced Settings.
      2. Type deprecated in the filter.
      3. Turn on RemoteAPI: Deprecated Api Enabled.
      4. If JDeck runs on another computer, turn off RemoteAPI: Deprecated Api Localhost Only.
      5. Restart JDownloader.

      Caution: JDownloader's local API has no password. After step 4, every device on your network can control JDownloader. To keep it closed, use JDeck Server on the JDownloader computer instead.
