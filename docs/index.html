JDeck is a small desktop app for JDownloader 2. Paste links, watch progress, and start or pause downloads from any computer at home. Phones and tablets can use it too, if you turn that on.

    Stays on your network

    No account, no cloud and no tracking. JDeck does not use MyJDownloader. It talks only to the JDownloader address you set.

    JDownloader stays as it is

    JDeck uses JDownloader's own local API. Turn on one setting in JDownloader. There is nothing to install on that machine.

    No installer

    Download one program and start it. Settings live in a folder next to it, so copying both moves everything.

    Send links. Watch them land.

    Everything JDeck shows comes from JDownloader and refreshes every 1.5 seconds.

    Paste anything

    Paste a message, a forum post or a list. JDeck finds every http, https and ftp link and removes duplicates.

      Check before you start

      Hold new links in the LinkGrabber. See file counts, sizes and offline files, then start or remove each package.

        Phones and tablets, if you want

        Network sharing is off by default. Turn it on, set a password, and open JDeck in any browser at home.

        Phones and other devices
        Let other devices on my network use JDeck

        On other devices, open http://192.168.1.20:8080 and sign in with the password.

        Download

        Free and open source. JDeck needs JDownloader 2 with its local API turned on. See the setup steps.

        Windows x64 · .exe

        Uses Microsoft Edge WebView2, part of Windows 10 and 11. The file is not code-signed: if SmartScreen warns, select More info, then Run anyway.

         macOS Apple Silicon · .zip

        Not code-signed. The first time, open System Settings > Privacy & Security and select Open Anyway.

         Linux x64 · .tar.gz

        Needs WebKitGTK, for example gir1.2-webkit2-4.1 on Ubuntu. Without it, JDeck opens in your browser.

        Prefer to run it yourself? JDeck runs from source with Python 3.10 or later. See Run from source.
